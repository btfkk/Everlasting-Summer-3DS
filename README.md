# Бесконечное лето — порт на Nintendo 3DS

Неофициальный фанатский порт визуальной новеллы **«Бесконечное лето»** (Soviet Games) на **Nintendo 3DS**.

**Версия:** beta 0.01 · **Автор порта:** btfkk

## Что есть

- Вся история: пролог, 7 дней, все концовки, эпилог и путь Жени.
- Фоны, спрайты, CG, переходы, музыка и звуки.
- Карта лагеря, шахта и карточная игра, как в оригинале.
- 3 страницы сохранений, быстрое сохранение, автосохранение и «Продолжить».
- Журнал, авточтение, пропуск текста, светлая и тёмная тема.
- Управление кнопками и сенсором.

## Чего пока нет

- Вступительного ролика.
- Отката назад (пользуйся сохранениями).

## Где проверялось

- **ПК:** эмулятор Azahar.
- **Anbernic RG DS:** прошивка ROCKNIX, эмулятор Azahar.

## Что нужно

- **3DS / 2DS / New 3DS / New 2DS** с кастомной прошивкой **Luma3DS**. Если её ещё нет, есть гайд: [3ds.hacks.guide](https://3ds.hacks.guide/ru_RU/).
- **FBI** (обычно ставится вместе с прошивкой по гайду).
- SD-карта, на которой свободно около 1 ГБ.
- Файл **`es3ds.cia`** из релиза.

Звук работает сразу, ничего дополнительно ставить не нужно.

## Установка

1. Выключи консоль и вставь SD-карту в компьютер.
2. Создай на карте папку `cia`, если её ещё нет, и скопируй туда `es3ds.cia`.
3. Вставь карту обратно в консоль и включи её.
4. Запусти **FBI** и открой **SD** → **cia** → **es3ds.cia**.
5. Выбери **Install and delete CIA** и подтверди кнопкой **A**. Файл большой, поэтому установка займёт несколько минут.
6. Выйди кнопкой **HOME**. На главном экране появится **Everlasting Summer**.

Если не хочешь вынимать карту, перекинь файл по Wi-Fi через **ftpd** или через **FBI → Remote Install**.

## Управление

| Кнопка | Действие |
|---|---|
| A / касание экрана | дальше |
| B / ↑ | журнал |
| X / START | меню |
| Y | быстрое сохранение |
| L / держать R | авточтение / пропуск |
| В картах: ←→ / A / X / B | выбор / взять или поменять / «Хватит» / отмена |

## Обновление и удаление

- **Обновление:** установи новый `es3ds.cia` через FBI поверх старого. Сохранения останутся.
- **Удаление:** FBI → **Titles** → **Everlasting Summer** → **Delete Title**.

Сохранения лежат в `sdmc:/3ds/es3ds/save/es3ds/`, журнал запуска — в `sdmc:/es3ds_log.txt`.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| FBI не видит файл | Проверь, что файл лежит в папке `cia` на SD-карте и заканчивается на `.cia`. |
| Ошибка при установке | Освободи место на карте и скопируй файл заново: он мог побиться при копировании. |
| Игра вылетает | Создай [Issue](../../issues) и приложи файл `sdmc:/es3ds_log.txt`. |
